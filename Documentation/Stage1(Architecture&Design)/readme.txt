ThreeAmigos Corp – ThAmCo System
Stage 1 Documentation

Prepared by: Ali Mustafa
ID: 2110097

Description:
This Stage 1 deliverable documents the architecture of the ThAmCo system, covering approximately 20% of the full system (Product Browsing & Search, User Authentication/Profile). It includes container diagrams, deployment diagrams, container specifications, connectivity and protocols, security and resilience strategies, and trade-offs made during design.

Purpose:
- Demonstrate container-based architecture
- Show inter-container connectivity and security
- Prepare for implementation stage (Stage 2)

Files Included:
- Architecture/: C4 diagrams and deployment/implementation diagrams
- Notes/: architecture overview, connectivity, containers, trade-offs
- techstack.txt: summary of all technologies
- readme.txt: overview and context
